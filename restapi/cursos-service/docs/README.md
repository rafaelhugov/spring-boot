# Documentacao tecnica - cursos-service

Este diretorio concentra a documentacao tecnica versionada do backend de Cursos.

## Estrutura

- `tests/`: planos, matrizes, checklists e relatorios de cobertura dos testes da API de Cursos.
- `security/`: desenho, matriz e achados de seguranca especificos do backend de Cursos.
- `api/`: planos de migracao e contratos relacionados aos endpoints do service.

Documentos compartilhados entre services devem ficar em `restapi-common/docs`. Documentos exclusivos do frontend Cursos devem ficar em `mppb-vue/cursos-web/docs`.
